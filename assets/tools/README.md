# Toolkit icons

These local SVG assets identify the tools named in the portfolio. Tool names and brand marks belong to their respective owners.

- excel.svg: Microsoft Excel mark from Simple Icons 11.15.0, https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/microsoftexcel.svg
- powerbi.svg: Power BI mark from Simple Icons 11.15.0, https://github.com/simple-icons/simple-icons/blob/11.15.0/icons/powerbi.svg
- colab.svg: Google Colab mark from Simple Icons, https://github.com/simple-icons/simple-icons/blob/develop/icons/googlecolab.svg
- looker.svg: Looker mark from Simple Icons, https://github.com/simple-icons/simple-icons/blob/develop/icons/looker.svg
- python.svg: Python original mark from Devicon, https://github.com/devicons/devicon/blob/master/icons/python/python-original.svg. Its MIT notice is included in DEVICON-LICENSE.txt.
- sql.svg: Original generic database illustration. SQL is a language rather than a single branded application.

Monochrome marks use recognizable product colors. Assets are hosted locally without third-party requests at runtime.

The context

Project overview

What I built

A web-based library companion for questions about hours, borrowing, renewals, resources and library policies, with source links attached to supported answers.

Why I built it

To make library information easier to find in natural language while keeping the supporting source visible.

The experience

Key features

Natural-language questions

A conversational interface covers hours, borrowing, renewals, resources, and library policies.

Visible supporting sources

Retrieved passages and citations connect an answer to its supporting library information.

Source-support fallback

Requests without enough source support receive a fallback response.

The approach

How it works

  • Retrieval-Augmented Generation
  • Semantic Search
  • Natural Language Processing
  • Text Chunking & Embeddings
  • Source Citations
  • Retrieval Evaluation

Python prepares the FAQ workbook, splits its text into passages and embeds them with Sentence Transformers. ChromaDB retrieves the three closest passages; Groq generates an answer with citations. Flask serves the interface and API. Requests without sufficient source support receive a fallback response.

What I learned

I learned how text preparation, chunking and retrieval quality affect whether a generated answer can be traced to its sources.
